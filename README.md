# HELLO KITTY CAMERA 🎀

레트로 CCD(캐논 익서스 70) 색감의 원페이지 웹 카메라.

---

> 📸 카메라(getUserMedia)는 **https 에서만** 동작합니다. GitHub Pages 는 기본이 https 라 그대로 됩니다.

---

## 2. 카카오톡으로 공유할 때

카카오톡 인앱 브라우저는 **확대/글자 크기 자동 조정**과 **카메라 차단** 두 가지 문제가 있습니다. 둘 다 대응해 두었습니다.

**레이아웃 깨짐 방지 (이미 적용됨)**

| 문제 | 처리 |
|---|---|
| 글자·배경 자동 확대 | `-webkit-text-size-adjust:100%`, `text-size-adjust:100%` |
| 핀치 / 더블탭 줌 | `user-scalable=no` + `gesturestart/change/end` 차단 + 더블탭 `preventDefault` |
| 스크롤·바운스 | `position:fixed`, `overscroll-behavior:none`, `touch-action:manipulation` |
| 툴바 때문에 화면 잘림 | 402×874 고정 스테이지를 `transform: scale()` 로 **통째로 축소** → 리플로우 자체가 없음 |
| visualViewport 변화 | `resize` / `scroll` 이벤트로 스케일 재계산 |

**카메라 차단 대응**
카카오 인앱에서 카메라가 막히면 하단에 **"브라우저로 열기"** 배너가 뜹니다.
- Android → `intent://` 로 Chrome 실행
- iOS → `kakaotalk://web/openExternal` 로 Safari 실행

## 3. 조작 방법

| 동작 | 위치 |
|---|---|
| **전원 ON / OFF** | 카메라 하단의 **빨간 전원 버튼** (켜지면 옆에 초록 LED) |
| **전/후면 전환** | 십자키 아래 빨간 버튼 (기존 MENU 자리, 라벨을  으로 교체) |
| **전/후면 전환** | 십자키 아래 빨간 버튼 (기존 MENU 자리, 라벨을 `전환` 으로 교체) |
| **촬영** | 오른쪽 십자키 가운데 **OK 버튼을 0.55초 꾹** (누르는 동안 링이 차오르고, 완료 시 화이트 플래시 + 셔터음) |
| **스티커** | 촬영 후 하단 트레이에서 탭 → 폴라로이드에 추가. 드래그로 이동, 우하단 ⤢ 드래그로 크기·회전, 좌상단 ✕ 로 삭제 |
| **저장** | `폴라로이드 저장` (프레임 포함) / `사진만 저장` (프레임 없이). 둘 다 **스티커가 붙은 그대로** 저장됨 |
| **다시 찍기** | 폴라로이드를 넣고 스티커 초기화 |

전원을 켜기 전에는 액정이 **검정**으로 보입니다.

## 4. 기능

- **실시간 라이브뷰** — 키티 카메라 PNG 의 액정을 실제로 뚫어 `<canvas>` 프리뷰를 넣었습니다.
- **캐논 익서스 70 CCD 프로파일** — 프리뷰와 결과물에 **동일한** 픽셀 파이프라인 (WYSIWYG)
  1. S-커브 콘트라스트 + 살짝 들린 블랙  2. 레드 +1 / 블루 +1 (*색상 선택적* 이라 흰색은 흰색 유지)
  3. 하이라이트 웜 / 섀도우 쿨  4. **피부톤 -1**  5. 채도 +1  6. 언샤프 마스크(선명도 +1)  7. 비네팅 + 필름 그레인
- **자체 내장 보정** — 촬영 순간에만 적용되는 아주 약한 워프: **눈 +10%**, **콧볼 -8%**, **턱선 V라인 3%**. 얼굴을 못 찾으면 보정을 건너뜁니다.
- **디지털 타임스탬프** — 캔버스로 그린 7-세그먼트 주황 날짜
- **홈 화면 앱** — iOS 사파리 → 공유 → *홈 화면에 추가* 하면 주소창 없이 앱처럼 실행됩니다. 아이콘은 키티5(사과) 이미지.
